# RB-03 Identidad: inicios de sesión y cuentas
**Reglas:** UC-IDP-001 a UC-IDP-007

## Comprobaciones
1. Origen: país, ASN, si es hosting, Tor o VPN comercial (`geoip_asn.csv`, TIP).
2. Dispositivo: ¿`device_id` conocido y conforme? ¿El user agent encaja con el usuario?
3. MFA: método y resultado. Muchos `timeout`/`denied` seguidos de un `approved` = fatiga MFA.
4. Contexto: viajes y bajas (`eventos_rrhh.csv`), tipo de cuenta (`usuarios.csv`: servicio, admin, VIP).
5. Qué hizo la sesión después (`idp_audit`): reglas de buzón, consentimientos OAuth, nuevos métodos MFA, descargas.

## Decisión
- Viaje notificado o dispositivo conocido → cerrar como benign/false positive.
- Sesión desde infraestructura del atacante, robo de cookie o persistencia (regla de buzón, OAuth, MFA nuevo) → proponer revocar sesiones, reset y retirar la persistencia; escalar.
- Cuenta de servicio comprometida → proponer deshabilitarla avisando del impacto de negocio.
