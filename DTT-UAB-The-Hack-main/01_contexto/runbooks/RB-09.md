# RB-09 Red: C2, escaneos y movimiento lateral
**Reglas:** UC-NET-001 a UC-NET-005

## Comprobaciones
1. Beaconing: intervalo y varianza, antigüedad del dominio, cuántos equipos lo contactan, user agent, proceso origen (EDR).
2. IP en TI: confianza y antigüedad del indicador.
3. Escaneo: ¿origen es el escáner autorizado y dentro de su ventana?
4. Movimiento lateral: cuenta usada, origen permitido (las `adm.*` solo desde JUMP01), cambio aprobado.

## Decisión
- Software conocido o escáner autorizado → cerrar y proponer exclusión en la regla.
- C2 con proceso sospechoso detrás o movimiento lateral no autorizado → proponer aislamiento y escalar.
