# RB-06 Cloud (AWS)
**Reglas:** UC-CLD-001 a UC-CLD-004

## Comprobaciones
1. Identidad y clave: ¿de dónde se usa normalmente? (buscar la misma `accessKeyId` en `cloudtrail`).
2. Origen y user agent nuevos, llamadas de reconocimiento (`GetCallerIdentity`, `List*`).
3. Persistencia: creación de usuarios, claves o políticas.
4. Datos: volumen de `GetObject` y clasificación del bucket.
5. Cambio aprobado o pipeline de Terraform conocido.

## Decisión
- Pipeline conocido → cerrar.
- Clave usada desde fuera → proponer desactivar la clave y las identidades creadas; si hay descarga de datos personales, implicar al DPO.
