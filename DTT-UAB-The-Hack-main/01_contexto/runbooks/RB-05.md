# RB-05 Tienda online, fraude y ataques web
**Reglas:** UC-WEB-001 a UC-WEB-003, UC-EDR-009

## Comprobaciones
1. ¿El WAF bloqueó? ¿La ruta existe y es vulnerable (`vulnerabilidades.csv`)? ¿Origen autorizado (pentest)?
2. Credential stuffing: volumen, IPs, huella del dispositivo y, sobre todo, **cuántos accesos correctos**.
3. Para cada acceso correcto: ¿cambio de email/dirección o compra de tarjeta regalo después (`ecom_account`)?
4. Web shell: ¿el servidor web lanzó una shell? ¿Qué leyó?

## Decisión
- Escaneo bloqueado o pentest autorizado → cerrar.
- Stuffing con accesos correctos → bloquear origen, activar captcha y rate limit, resetear cuentas afectadas, avisar al equipo de Fraude.
- Web shell → proponer aislar el nodo (quedan otros frontales), rotar secretos y escalar.
